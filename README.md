# MDR Tech — Software Solutions Portfolio

A modern, responsive portfolio website built to showcase software development services, projects, and provide an easy way for clients to get in touch.

**Live Site:** [https://mdrtech.netlify.app](https://mdrtech.netlify.app)

---

## 📖 About

MDR Tech is a personal portfolio and business website for **Daniyal Rashid**, a Software Engineer and Full Stack Developer. The site highlights services offered (web development, app development, UI/UX design, AI integration, and more), showcases completed projects, and provides a direct contact channel for potential clients.

---

## ✨ Features

- 🎨 Clean, professional light-themed UI with custom brand colors
- 🔄 Animated rotating hero text (Full Stack Developer / AI Integration Expert / Your Digital Partner)
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎬 Smooth scroll-triggered animations using Framer Motion
- 💼 Dedicated sections for Services, Projects, and Pricing
- 📧 Working contact form with instant email notifications (no backend required)
- 🔗 Direct links to GitHub, LinkedIn, and project repositories
- ⚡ Fast performance with Next.js App Router
- 🆓 Fully deployed on free-tier hosting (Netlify)
